Başlamadan önce

  1. Ethernet kablosunu bağlayın.Bilgisayarın Ethernet adaptörünü açık Vantiva’nın WAN / Internet portuna bağlayın.
  2. Doğru adaptörü seçin.Bu cihazın router’a bağlı Ethernet adaptörünü seçip kontrol edin.
  3. WAN cihazını keşfedin.Keşfi başlatın ve bulunan cihazı seçin. Yanıt yoksa WAN kablosunu çıkarıp takın. Varsayılan VLAN: 35.
  4. Önce salt okunur keşfi başlatın.Önce bağlantıyı doğrulayın. Test için internet gerekmez. SSH girişi için router’ın LAN veya Wi-Fi ağına bağlanın.
